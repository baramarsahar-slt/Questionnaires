# שאלונים — סהר

שאלוני הערכה-עצמית נוירו-אפירמטיביים למטופלים, מבית הקליניקה "סהר".
כל שאלון הוא דף HTML עצמאי. התשובות נשלחות ונשמרות ב-Google Drive של המטפלת,
בתיקייה נפרדת לכל משיב לפי השם שהוזן.

## שאלונים
- `index.html` — "איך אני קולט את העולם" (חושים, ויסות, קשב) · נוסח מבוגרים צעירים

## איך השמירה עובדת
הדף הסטטי לא יכול לכתוב ל-Drive בעצמו. השמירה מתבצעת דרך סקריפט
Google Apps Script (`apps-script/Code.gs`) שרץ בחשבון הגוגל של המטפלת
ושומר תחת: `My Drive / קליניקה / טיפולים / <שם המשיב> /`.

## פריסת ה-Apps Script (פעם אחת)
1. להיכנס ל-https://script.google.com ← **New project**.
2. להדביק את התוכן של `apps-script/Code.gs` (למחוק את ברירת המחדל קודם).
3. **Deploy ← New deployment ← Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
4. לאשר את בקשת ההרשאה (גישה ל-Drive) — זה מה שמאפשר את השמירה.
5. להעתיק את ה-**Web app URL**.
6. למסור את הכתובת כדי שתוזרק ל-`GAS_URL` בראש ה-`<script>` ב-`index.html`.

## הערות
- ה-repo מכיל רק את הטופס הריק — **אין בו נתוני מטופלים**.
- התשובות זורמות ישירות ל-Drive הפרטי של המטפלת.
- עד שה-`GAS_URL` מוזרק, הטופס פועל במצב מקומי (שמירה בדפדפן + העתקת סיכום ידנית).
