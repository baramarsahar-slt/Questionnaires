# שאלונים — סהר

שאלוני הערכה-עצמית נוירו-אפירמטיביים למטופלים, מבית הקליניקה "סהר".
כל שאלון הוא דף HTML עצמאי, מתארח ב-GitHub Pages.

## שאלונים
- `index.html` — "איך אני קולט את העולם" (חושים, ויסות, קשב) · נוסח מבוגרים צעירים

## איך זה עובד
- הממלא עונה בדפדפן. התשובות נשמרות זמנית במכשיר שלו בלבד (localStorage).
- בסיום, "הצג סיכום" מפיק תמונת מצב שאפשר **לשמור כקובץ טקסט**, **להדפיס / לשמור כ-PDF**, או **להעתיק**.
- הממלא מביא או שולח את הקובץ למטפל/ת בעצמו. **שום נתון לא נשלח אוטומטית לאף אחד.**

## פרטיות
ה-repo מכיל רק את הטופס הריק — אין בו נתוני מטופלים. הנתונים נשארים על מכשיר הממלא עד שהוא בוחר לשתף.
