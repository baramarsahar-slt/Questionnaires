# שאלונים — סהר

שאלוני הערכה-עצמית נוירו-אפירמטיביים למטופלים, מבית הקליניקה "סהר".
אתר רב-עמודים המתארח ב-GitHub Pages, עם מנוע משותף אחד לכל השאלונים.

## מבנה
- `index.html` — עמוד נחיתה (בחירת שאלון)
- `sensory.html` — "איך אני קולט את העולם" (חושים, ויסות, קשב)
- `language.html` — "השפה והתקשורת שלי"
- `styles.css` — עיצוב מותג "סהר" המשותף לכל העמודים
- `questionnaire.js` — מנוע משותף שמרנדר כל שאלון מתוך אובייקט `window.QUESTIONNAIRE`
- `logo.png` — הלוגו

## הוספת שאלון חדש
יוצרים עמוד HTML חדש (כמו `sensory.html`), מגדירים בו `window.QUESTIONNAIRE`
(storeKey ייחודי, title, lead, reflect, domains), ומוסיפים כרטיס אליו ב-`index.html`.
אין צורך לשכפל עיצוב או לוגיקה.

## איך זה עובד
- הממלא עונה בדפדפן. התשובות נשמרות זמנית במכשיר שלו בלבד (localStorage).
- בסיום, "הצג סיכום" מפיק תמונת מצב שאפשר **לשמור כקובץ**, **להדפיס / לשמור כ-PDF**, או **להעתיק**.
- הממלא מביא או שולח את הקובץ למטפל/ת בעצמו. **שום נתון לא נשלח אוטומטית.**

## פרטיות
ה-repo מכיל רק את הטפסים הריקים — אין בו נתוני מטופלים. הנתונים נשארים על מכשיר הממלא עד שהוא בוחר לשתף.
